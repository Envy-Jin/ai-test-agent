# 用户登录功能需求

## 功能描述
用户可以通过手机号或邮箱登录系统，系统验证用户身份后返回访问令牌。

## 输入字段
- 手机号：11位数字，以1开头，必填（二选一）
- 邮箱：标准邮箱格式（xxx@xxx.xxx），必填（二选一）
- 密码：不少于8位，必须包含数字和字母，必填

## 约束条件
- 密码错误超过5次锁定账号30分钟
- 同一账号最多3个设备同时在线
- 连续3次登录失败需输入图形验证码
- 登录成功后生成JWT Token，有效期2小时
- 支持"记住我"功能，Token有效期延长至7天

## 非功能需求
- 登录接口响应时间不超过500ms
- 支持1000并发登录请求
- 密码传输使用HTTPS加密

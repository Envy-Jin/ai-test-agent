# 力扣登录/注册页 - UI 测试分析报告

**页面描述**：提供手机号验证码登录、第三方登录及账号密码登录入口的页面

**分析摘要**：页面采用居中卡片式布局，包含手机号与验证码输入框、登录/注册按钮、第三方登录图标及协议链接。顶部有导航栏，底部有页脚信息。

## 三、详细测试步骤

### TC001 - 手机号验证码正常登录
- **类型**：正向 | **优先级**：P0 | **范围**：UI可测 | **目标元素**：登录/注册
- **元素 ID**：EL003
- **步骤**：
  1. 输入有效手机号
  2. 点击获取验证码
  3. 输入正确验证码
  4. 点击登录/注册
- **预期**：登录成功并跳转至首页

### TC002 - 手机号为空提交

  1. 不输入手机号
  2. 点击登录/注册
- **预期**：提示手机号不能为空

### TC003 - 手机号少于11位提交

- **元素 ID**：EL001
- **步骤**：

### TC004 - 手机号刚好11位提交

## 四、潜在视觉/可用性问题

- ⚠️ 登录卡片右上角的扫码登录图标与卡片边框间距较紧凑
- ⚠️ 底部协议文字颜色较浅，可能存在对比度不足的可用性风险

# 登录服务接口文档

## 基础信息
- 服务地址：http://127.0.0.1:8766
- 协议：HTTP / JSON
- 鉴权方式：Bearer Token（登录成功后获得，有效期 2 小时）

## 接口一：用户登录
- 路径：POST /api/login
- 功能说明：手机号 + 密码登录，成功返回访问令牌
- 是否需要鉴权：否（登录接口本身用于获取 token）
- 正常响应（200）：{"code": 0, "message": "登录成功", "data": {"token": "..."}}

### 请求参数
| 名称 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|------|------|------|------|------|--------|
| phone | body | string | 是 | 11 位手机号，1[3-9] 开头 | 13800138000 |
| password | body | string | 是 | 不少于 8 位，须含数字和字母 | Test123456 |

### 错误响应
- 400：参数缺失（code=40001）/ 密码长度不足（code=40002）/ 手机号格式错误（code=40003）
- 401：手机号或密码错误（code=40101）

### 响应体结构（断言字段）
code、message、data.token

## 接口二：查询订单列表
- 路径：GET /api/orders
- 功能说明：查询当前登录用户的订单列表
- 是否需要鉴权：是（请求头 Authorization: Bearer <token>）
- 正常响应（200）：{"code": 0, "data": {"orders": [{"id": "ORD-1001", "amount": 99.5}]}}

### 请求参数
无

### 错误响应
- 401：缺少或无效 token（code=40101）

### 响应体结构（断言字段）
code、data.orders

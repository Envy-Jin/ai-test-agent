# Bug 报告：用户登录模块（2026-08-30 批次）

## BUG-L01 错误密码提示文案错误（一般 · 待修复）
- 环境：Chrome 126 / Windows 11 / 生产环境
- 复现步骤：
  1. 打开登录页
  2. 输入手机号 13800138000
  3. 输入错误密码 WrongPass1
  4. 点击登录按钮
- 期望：提示"手机号或密码错误"
- 实际：提示"系统繁忙，请稍后再试"
- 日志：POST /api/login → 401 {"code": 40101, "message": "invalid credentials"}

## BUG-L02 登录成功后 token 未写入本地存储（严重 · 已修复）
- 环境：iOS Safari / 生产环境
- 复现步骤：
  1. 手机号 13800138000 + 正确密码登录
  2. 登录成功后检查 localStorage
- 期望：写入 auth_token
- 实际：localStorage 为空，刷新后掉登录态
- 修复记录：2026-08-28 v1.4.2 修复（token 写入逻辑移到登录成功回调）

## BUG-L03 密码输入框长度无上限（轻微 · 待修复）
- 环境：全端
- 复现步骤：
  1. 在密码框粘贴 1000 位字符
  2. 提交登录
- 期望：前端限制最大 64 位并提示
- 实际：请求体超长，后端返回 400 code=40004（未定义错误码）

## BUG-L04 连续输错 5 次未锁定账号（严重 · 已修复）
- 环境：生产环境
- 复现步骤：
  1. 连续输入错误密码 5 次
  2. 第 6 次输入正确密码
- 期望：第 5 次后账号锁定 30 分钟
- 实际：第 6 次正确密码直接登录成功
- 修复记录：2026-08-27 v1.4.1 修复（错误计数复位逻辑）

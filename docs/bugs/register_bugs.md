# Bug 报告：用户注册模块（2026-09-16 批次）

## BUG-R01 验证码错误仍能注册成功（严重 · 待修复）
- 环境：Chrome 126 / Windows 11 / 测试环境
- 复现步骤：
  1. 打开注册页
  2. 输入手机号 13900139000
  3. 输入任意错误验证码 000000
  4. 点击注册按钮
- 期望：提示"验证码错误"，返回 401（code=40101），不创建账号
- 实际：返回 200，账号被创建，自动登录
- 日志：POST /api/register → 200 {"code": 0, "data": {"user_id": "U10001"}}
- 影响：验证码形同虚设，可批量注册垃圾账号

## BUG-R02 同一手机号可重复注册（严重 · 待修复）
- 环境：全端 / 测试环境
- 复现步骤：
  1. 用手机号 13900139000 完成注册
  2. 退出后再次用同一手机号 + 新验证码注册
- 期望：提示"该手机号已注册"（400 或 409），不创建新账号
- 实际：注册成功，同手机号产生 2 个 user_id
- 影响：数据唯一性被破坏，下游按手机号查询会拿到多条记录

## BUG-R03 密码强度校验缺失（一般 · 待修复）
- 环境：全端
- 复现步骤：
  1. 注册时密码输入 "12345678"（纯数字，8 位）
  2. 提交注册
- 期望：拒绝并提示"密码须同时包含数字和字母"
- 实际：注册成功
- 日志：后端仅校验长度 >= 8，未校验字符组成
